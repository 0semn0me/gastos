# Gastos in Home

Controle de gastos domésticos feito em HTML puro.  
Funciona offline e salva tudo no próprio navegador.

## Como usar

1. Baixe o arquivo `gastos-in-home.html`
2. Abra no navegador (Chrome, Safari, Edge, Firefox…)
3. Pronto — os dados ficam salvos localmente

## Funcionalidades

- Lançamento de gastos com categoria, vencimento e responsável
- Divisão de contas (50/50, proporcional à renda ou só de uma pessoa)
- Controle de pagos e pendentes
- Planejamento com reservas e projeção de saldo
- Temas claro / escuro
- Backup e restauração em JSON
- Exportar extrato em PDF ou HTML compartilhável

## Backup

Dentro do app, em **Ajustes → Backup**, você pode baixar ou restaurar seus dados a qualquer momento.

## Observação

Os dados ficam apenas no navegador do dispositivo.  
Para usar em outro celular/computador, use a função de backup.
